# DateCalHTML

簡易網頁版日期計算工具。

這個專案是一個輕量、單頁式的 HTML 工具，主要供日常快速進行日期相關計算使用。  
不需要安裝 App，也不需要後端伺服器，直接使用瀏覽器即可執行。

## 線上版本

Netlify：

https://funeralcalculator.netlify.app/

## 專案定位

這是一個以簡單、快速、實用為目的的小型工具。

主要特色：

- 純網頁版本
- 不需要安裝
- 不需要帳號
- 不依賴後端服務
- 可直接部署至 Netlify
- 適合手機與電腦瀏覽器使用

## 專案結構

本專案以單一 HTML 頁面為主，HTML、CSS 與 JavaScript 可能集中於同一檔案內。

因此沒有複雜的建置流程，也不需要 npm、Node.js 或其他套件管理工具。

## 使用方式

### 線上使用

直接開啟：

https://funeralcalculator.netlify.app/

### 本機使用

下載專案後，直接使用瀏覽器開啟主要 HTML 檔案即可。

不需要額外安裝任何環境。

## 部署

目前正式版本部署於 Netlify。

這是純靜態網頁，因此 Netlify 可以直接由 GitHub Repository 部署，不需要額外的 Build Command。

基本流程：

GitHub Repository
→ Netlify
→ funeralcalculator.netlify.app

GitHub 更新後，可由 Netlify 自動重新部署。

## 維護原則

這個專案主要供個人日常使用，因此維持：

- 簡單
- 穩定
- 容易維護
- 不加入不必要的框架與相依套件

除非有明確功能需求，否則盡量維持目前單純的 HTML 架構。
